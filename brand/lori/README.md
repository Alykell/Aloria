# Lori, la mascotte d'Aloria

Un axolotl (créature de Minecraft, aquatique comme le thème d'Aloria) aux couleurs du logo : turquoise, branchies roses.

- `lori*.svg` : une tête par expression (lori, gg, love, wow, cry, think, pvp), générées par `lori.py`
- `lori*.png` (512 px) et `lori*-128.png` (emojis Discord)
- Régénérer : `python lori.py`, puis `npx electron brand/lori/render.cjs <dossier brand/lori absolu>` depuis la racine du dépôt
