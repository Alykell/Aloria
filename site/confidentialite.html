Confidentialité

En bref : Aloria ne collecte aucune donnée. Pas de compte Aloria, pas de statistiques, pas de publicité.

Ce qui reste sur ton PC

Tes comptes Microsoft (jetons de connexion), profils, réglages, mondes et mods sont enregistrés uniquement sur ton ordinateur, dans %APPDATA%\.aloria et %APPDATA%\Aloria. Les jetons de connexion sont chiffrés avec la protection de Windows (DPAPI). Aloria ne les envoie qu'aux services officiels listés ci-dessous.

Les services qu'Aloria contacte

Aloria communique uniquement avec ces services, et seulement pour ce dont tu as besoin :

  • Microsoft, Xbox Live et Mojang : connexion à ton compte quand tu te connectes, vérification que tu possèdes Minecraft, et téléchargement officiel du jeu et de Java quand tu lances un profil. Politique de confidentialité de Microsoft.
  • Fabric (meta.fabricmc.net) : téléchargement de Fabric pour les profils qui l'utilisent.
  • Modrinth : recherche et téléchargement des mods, packs de ressources et shaders que tu choisis. Politique de confidentialité de Modrinth.
  • GitHub : au démarrage, Aloria vérifie s'il existe une nouvelle version et la télécharge. Aucune donnée personnelle n'est envoyée, seulement la demande de téléchargement. Politique de confidentialité de GitHub.
  • Discord : si Discord est ouvert sur ton PC, Aloria affiche ton statut de jeu (profil, version, serveur selon tes choix). Cela passe par Discord sur ton ordinateur ; tu peux le désactiver dans les Paramètres d'Aloria. Politique de confidentialité de Discord.

In English

This program will not transfer any information to other networked systems unless specifically requested by the user or the person installing or operating it, except for the automatic update check described above (a download request to GitHub, without personal data). Sign-in tokens are stored only on the user's computer, encrypted with the Windows data protection API, and are only sent to Microsoft, Xbox Live and Mojang.

Désinstallation

Aloria se désinstalle depuis Windows (Paramètres → Applications). Tes mondes et réglages sont conservés dans %APPDATA%\.aloria : supprime ce dossier pour tout effacer.
